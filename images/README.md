## 上传方式（二选一）

### 方式 A：GitHub 网页上传（推荐，免命令）
1. 打开仓库页面 `github.com/tangming158/tm`
2. 进入分支 `cursor/wuhou-grade7-math-outline-7eda`
3. 进入 `images/` 文件夹 → 点 `Add file` → `Upload files`
4. 把 7 张图（按上表命名）拖进去 → 填写提交说明 → `Commit changes`

### 方式 B：本地 git 推送
```bash
git add images/
git commit -m "上传舞台主图素材"
git push
```
